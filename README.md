# AnimeAPI for Dify

Anime image generation in [Dify](https://dify.ai) with [AnimeAPI](https://animeapi.ai) at **$0.003 per image**, one of the cheapest anime image APIs. Prepaid balance from $5 that never expires, no subscription; new accounts get 3 free images without a card.

The plugin adds one tool, **Generate Anime Image**, for agents, chatflows and workflows. You (or your model) describe the picture in plain words; the tool returns the image as a file that Dify stores, plus the price and your remaining balance.

## Setup

1. Create an AnimeAPI key at <https://animeapi.ai/dashboard/api-keys> (keys start with `ank_`).
2. In Dify, install **AnimeAPI** from the Marketplace (**Plugins → Marketplace**).
3. Open **Tools → AnimeAPI → Authorize** and paste the key. The key is checked without generating anything.

The plugin connects to one host only, `https://animeapi.ai`. A self-hosted Dify needs outbound HTTPS access to it.

## Use

- **Agent / Chatbot with tools:** add **Generate Anime Image** to the app's tools and ask for a picture: *"Draw a cheerful witch flying over a moonlit city, landscape."* The model writes the prompt and picks the shape.
- **Workflow / Chatflow:** add the tool as a node, map a text variable to **Prompt**, and use the node's `files` output (the image), `text` (price and balance) or `json` (details) downstream.

### Inputs

| Input | Default | What it does |
| --- | --- | --- |
| Prompt | required | What to draw, in plain words. Up to 1000 characters. |
| Orientation | `portrait` | `portrait`, `square` or `landscape`. Same price for every shape. |
| Model | `anime` | `anime` $0.003, `ultra` $0.01, `ultra-max` $0.02 per image. Set by you, not by the model, so an agent cannot pick a more expensive one. |
| Enhance prompt | on | Rewrites plain words into tags for the anime model. Turn off to send your own tags unchanged. |

AnimeAPI does not generate adult content. Explicit prompts are refused and not charged.

### Outputs

- `files`: the generated image, stored by Dify. AnimeAPI image links are not permanent storage, so the plugin hands Dify the file itself.
- `text`: one line with the price and the balance left, for example `Generated 1 anime image (landscape) for $0.003. Balance left: $4.97.`
- `json`: `image_url`, `model`, `orientation`, `enhanced_prompt`, `price_usd`, `balance_usd`, `generation_time_ms`.

When a request fails (wrong key, empty balance, refused prompt), `text` carries AnimeAPI's own message and no file is returned. Failed and refused requests cost nothing.

## Prices

| Model | Price per image | Use it for |
| --- | --- | --- |
| `anime` | **$0.003** | Characters, portraits, avatars, scenes. About 4 seconds. |
| `ultra` | $0.01 | Long, detailed prompts; legible text in the image. |
| `ultra-max` | $0.02 | Highest detail. |

## Tested

Run against Dify Cloud on 2026-11-12 through remote debugging: a wrong key was rejected at authorization, a real key accepted, and a workflow (Start → Generate Anime Image → End) returned the image above as a stored file in about 7 seconds for $0.003. An explicit prompt came back with AnimeAPI's refusal message and the balance unchanged.

## Privacy

The plugin sends your key, the prompt and the options to AnimeAPI and nothing else. See [PRIVACY.md](PRIVACY.md).
